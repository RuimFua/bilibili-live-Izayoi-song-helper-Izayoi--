# 直播点歌小帮手 (Bilibili Live Song Helper)

这是一个为 Bilibili 直播间开发的油猴脚本，旨在帮助用户高效地进行点歌、打 Call 以及快捷弹幕互动。

## 功能特性
- **歌单管理**：支持搜索、按语言（中文、日语、英语、粤语）筛选歌曲。
- **互动助手**：支持一键“填入”或“直接发送”点歌指令。
- **自定义打Call**：支持保存个性化打 Call 词，并可一键追加到输入框。
- **界面友好**：清新白底 UI，支持拖拽、缩放，并内置一键重置位置功能。
- **边界保护**：自动检测窗口位置，防止插件超出屏幕范围。

## 安装指南
1. **安装环境**：请确保你的浏览器已安装 [Tampermonkey (油猴)](https://www.tampermonkey.net/) 插件。
2. **脚本安装**：
   - 点击本仓库中的 `.user.js` 文件。
   - Tampermonkey 会自动识别并弹出安装界面，点击“安装”即可。
3. **配置歌单**：
   - 在脚本编辑器中，找到 `const SONG_DATA` 部分。
   - 将你的歌单数据 (JSON 格式) 替换掉原有的示例数据。
4. **刷新页面**：前往 Bilibili 直播间，刷新页面即可看到悬浮窗。

## 使用说明
- **拖拽**：按住标题栏区域即可移动面板。
- **缩放**：按住右下角的灰色三角区域可调整窗口大小。
- **重置**：点击标题栏的 `↺` 按钮，可将面板恢复至右下角初始位置。
- **打Call**：点击 `+` 号选择参考词，或输入自定义词保存。点击标签即可将词追加到输入框。
